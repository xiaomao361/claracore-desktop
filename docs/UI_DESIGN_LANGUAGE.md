# Design language

The desktop interface and project website share a restrained visual identity:
cool white surfaces, deep purple text, lavender continuity lines, and ice-blue
endpoints. The open C, shared line, and inner point are the canonical mark.
Use the source assets in [`assets/brand/`](../assets/brand/).

| Role | Color |
| --- | --- |
| Body text | `#25242c` |
| Shared line | `#6f54a3` |
| Endpoint accent | `#4a7aa5` |
| Light background | `#fbfbfd` |
| Dark background | `#1b1b20` |
| Dark text | `#ecebf1` |

Color supports structure; it must not be the sole indicator of state. Keep
focus visible, controls labeled, reading order predictable, and reduced motion
supported. Use adequate contrast for body text and muted labels.

Home presents the current shared position and the next meaningful action.
Deep history and diagnostics are explicitly opened. Counts are operational
signals, not proof that content has been understood or used. InnerLife may
appear only through its eligible sharing path, not through a pending count.

The website uses brand illustration and a semantic architecture diagram.
Illustration is not an application screenshot or evidence of a product feature.
Source and generation notes are in [Assets](../assets/README.md).
