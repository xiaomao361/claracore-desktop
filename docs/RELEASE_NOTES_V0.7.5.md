# 0.7.5 — 运行状态与恢复验证

2026-09-11，个人 Mac arm64 Lite；未公开发布。

## 改动

现有「设置 → 应用与数据 → 数据与恢复」增加运行状态：

- 最近通过验证的本机备份时间、最近完成的每日备份日期。
- 最近一次自动备份的本机失败、额外副本失败、清理失败或旧目录离线待清理；附恢复建议和记录时间。
- 当前额外目录是否有最近一次执行的验证证据。历史验证不代表外盘此刻在线；更换目录不沿用原目录成功状态。
- 当前 provider/model/dimension 下普通 active、非 restricted 记忆的 ready 向量覆盖；未启用与未观察到搜索分别显示。
- 当前 ProductDatabase 实例最近的向量搜索成功/失败；失败保留关键词搜索结果。只保留状态，不保存查询正文或向量。
- 本次 Gateway 启动后最近工具请求的 Agent、实际处理协议和时间。只发现能力或初始化不算工具请求；这不是所有 Host 的协议清单。

设置页参与可见页定时刷新，保持未保存备份配置。刷新等待超过 15 秒时释放刷新循环并使旧请求失效；迟到结果不能覆盖新状态。超时不取消主进程中已经开始的操作。

系统恢复事件重新计算夜间调度并尝试待处理向量任务。当天维护已完成但每日备份尚未完成时，允许单独补备份，不重复执行当天清理。恢复事件监听随调度停止移除。失败保留原有退避重试。

- `node core/tests/modern-mcp-http-smoke.js`：官方 SDK 与隔离 HTTP 实例验证实际协议观测。
