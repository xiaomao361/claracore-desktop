# 0.8.1 — 知识搜索与收录体验

2026-09-29。0.8.1 发布候选；用户完成本地 Lite 试用并反馈无明显问题，授权发布 GitHub Release。正式资产验证在发布流程中记录。

## 相对 0.7.7 的新增能力

- 独立本地知识库：选择 Markdown 目录，保留原文件作为唯一正文，不复制进 Memory。
- 单栏阅读与双栏参考阅读、目录、小节定位、正反向链接及阅读历史。
- 有来源的收录预览、提交、读回、冲突检测、恢复副本与待整理入口。
- 文字、语义及混合检索；本机向量模型、可暂停继续的索引准备和明确失败状态。
- 设置中的可选决策模型与 query-only shadow 观察，不授予实际路由权。
- 显式协商的 Memory/Knowledge 上下文协议，保留旧宿主兼容性。

## 0.8.1 体验改进

- 人用「按文字」及混合检索的文字部分忽略大小写与首尾空格，优先展示命中小节标题、文档标题的结果；MCP exact 仍保持严格原文匹配。
- 显式更新语义索引完成后尝试更新结构索引，并自动重试当前已提交查询。暂停（含最后一批完成时）、输入变化、切换方式、换目录及离开页面不会重放旧查询。结构索引更新失败保持独立可见。
- 搜索结果分别标注小节日期与文档创建日期；来源显示简短标签，完整来源仍从原小节读取，不跨小节推断归属。
- 收录回执说明当时的搜索准备状态；待整理材料明确不参与知识搜索，历史回执不冒充当前索引状态。
- 增加可重复的真实语料检索基准及 20 条人工选定查询。

## 验证

`npm run check`、`git diff --check`、隔离 Lite flavor 检查通过。内存 DOM 回归覆盖查询恢复、更新期间修改查询、最后一批暂停、结构索引失败可见、来源日期展示和既有双栏交互；没有操作用户窗口。

真实库 47 篇、306 节，本机 Ollama bge-m3:latest；仅在临时目录建立索引。10 条文字正例、6 条语义正例均在前三项命中期望小节，4 条负例均正常无结果，合计 20/20。文字查询 6–16 ms，语义查询 97–132 ms；这是本次模型已就绪时的单次观察，不是冷启动或压力测试。案例由 Agent 根据原文选定，不是独立盲测、总体准确率或下游使用成效。未据此调整模型或 0.55 阈值。

真实语料案例与逐项结果保留在本地，公开源码仅提供通用评测脚本。

## 待验边界

当前 Codex 宿主仍要求 Memory-only，0.8.1 没有改变宿主指令；服务端知识投递协议和认证临时 HTTP MCP 回归通过，实际对话注入与采用仍需宿主接入。Jev 保持 query-only shadow。

本轮未修改真实知识正文或运行中应用的索引；现有应用不会因源码与打包完成而自动更新。用户已反馈 0.8.1 本地 Lite 试用无明显问题；未逐项声明窄窗口、暗色和所有平台交互验收。当前正按仓库正式发布流程完成源码与安装包发布。
