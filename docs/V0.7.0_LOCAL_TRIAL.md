# 0.7.0 本机隔离试用

当前产物：unsigned Mac arm64 Lite `0.7.0-preview.2`，包含增量向量检索和现代
HTTP MCP 核心。正式版本仍为 0.6.14。未安装或启动 UI。

## 启动入口

用户运行下面的文件，不要直接打开包内 App 或覆盖 /Applications 中的日用版：

`/Users/zhouwei/Library/Application Support/claracore-desktop-trials/v0.7.0-seLjbT/启动隔离试用.command`

它指向 `out/v0.7.0-local-trial/mac-arm64/ClaraCore Desktop.app`，使用同目录中的
私有数据副本与 user-data，显式开启 sqlite-vec。数据来自 09-09 只读快照，
不是之后日用库的实时镜像；试用修改不会自动写回日用库。
Gateway 使用独立随机端口，后台 InnerLife、embedding 队列和维护调度暂停。
手动自然语言搜索仍使用副本内的 embedding 服务配置；其调用尚未在本轮验收。

## 人工验收

1. 通过启动脚本打开试用，确认版本 0.7.0-preview.2；查看 Memory 列表是否正常。
2. 搜索几条熟悉的当前事实，对比命中和等待时间；重启后重复首次搜索。
3. 在副本中创建/修改一条测试记忆，检查关键词结果。后台 embedding 暂停，
   新记忆不会自动生成向量；不能把这一点误判成增量索引失效。
4. 在试用的 Agent Access 获取独立 endpoint，在 Claude/Hermes 进行实际互通，
   记录 Host 版本、现代协议请求及读写结果。不要覆盖日用 endpoint。

上述 UI 和 Host 操作由用户执行；源码/包内自动化通过不能代替这些观察。

## 已验证与未完成

通过：官方 SDK 2.0.0 modern discovery/list/create/search、鉴权/Origin/身份隔离、
协议错误与工具错误、core/full 目录、modern/legacy 背压、Node/CLI 向量回归、
包内向量与现代 Gateway，以及基础 check。后台暂停开关通过源码/构建核对，
未做 UI 运行验收。

待验收：人工体验、自然语言 embedding 调用、Claude/Hermes B3、Windows 和签名
分发；50k 首次构建约 16.8 秒与完整 A3 对照仍未解决，不阻挡这次小库隔离试用。

重建使用 `npx electron-builder --mac --dir --config scripts/trial-builder-config.js`。
重新准备副本使用 `node scripts/prepare-local-trial.js /absolute/App.app /absolute/snapshot.db`；
该命令只准备新的独立目录，不启动 App 或替换现有数据。
