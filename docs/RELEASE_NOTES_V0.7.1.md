# 0.7.1 — 页面数据刷新修复

2026-09-09，个人 Mac arm64 Lite 安装包，未公开发布。

## 修复

0.7.0 的已访问页面使用 hydratedViews 缓存，而原轮询仅更新资源监控。
通过 HTTP、独立 stdio 或 CLI 更新数据后，渲染进程不一定收到 runtimeChanged，
因此记忆、Shared Line 等页面可能长期保留旧快照。

数据页面可见时每 30 秒重新读取紧凑快照并更新当前页面；窗口重新可见、
获得焦点和切换页面时触发刷新。隐藏窗口暂停轮询。
后台刷新不重画设置表单；输入控件获得焦点、打开对话框或记忆搜索词非空时暂缓，
避免覆盖正在编辑的内容或把搜索结果换成最近列表。读取失败保留原快照并记录错误，
后续周期继续尝试。没有新增数据迁移。
