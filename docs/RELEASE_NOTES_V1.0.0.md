# 1.0.0 — 从共同理解继续

2026-10-20 发布准备。用户于 10 月 19 日确认当前 GUI 与品牌更新的整体效果，
批准版本号推进至 `1.0.0`，并于 10 月 20 日授权正式发布。
发布目标沿用 macOS arm64 与 Windows x64 的 Full/Lite 四种安装包。
发布状态与最终资产校验记录将在验证完成后补齐。

## 本版体验

- 首页围绕选中的共同线阅读主题、当前位置、下一步与记录的依据。记忆、知识、
  共同线、内在活动四处汇聚到同一块阅读面；实线只标记已记录的关系。
- 多个 Agent 可同时展示各自名称、稳定形状与色调。正在交互、刚有活动、最近
  来过分别依据请求观察表达，提供呼吸、单次涟漪、暂停和减少动态效果支持。
  保留现有 Agent 图标方案，不增加第三方品牌图标库。
- 当前主题与共同线完整阅读采用安全的只读排版，整理段落、小标题、列表、
  强调、代码与明确编号的步骤；完整阅读保留正文与全部引用。
- 白色、淡紫、冰蓝统一导航与阅读面。产品 Logo 保留 C、共同线和节点，更新
  配色与轻阴影，并生成应用图标、彩色托盘和深浅色顶部 Logo。

## 版本与边界

本版也包含自上一公开版本 `0.8.1` 以来的底层改进：

- `understanding_context / understanding_submit / understanding_resume` 组织
  有界共同上下文、逐事件证据计划、四域授权执行和可恢复回执。原模块继续拥有
  业务数据，模型调用与执行均需显式允许，宿主事件桥默认关闭。
- 通用决策模型配置、独立凭据、Shared Line 精确目标回执、有界诊断目录和
  显式 Memory 使用反馈。可选模型保持原有开关与权限，不因安装升级自动启用。
- 共同理解上下文不等于已确认共识，模型结构校验不等于真实语义质量。
  历史真实模型评测的失败和待复验边界仍保留；本次发布不追加付费模型调用，
  不声明外部 Hermes 客户端补丁已随 DMG 安装。

`package.json`、锁文件与经复核的 Agent Guide 均为 `1.0.0`，Guide 日期为
`2026-10-19`。界面与运行时通过 `core/version.js` 读取产品版本，安装包元数据
同步为 `1.0.0`。

从上一份 GUI 试用包到正式发布准备，不新增模型调用、数据迁移或 Agent
契约变更。首页仍基于已有记录展示共同理解，不自动读取待分享的 InnerLife
正文，也不将装饰连线视为实时业务流转。
