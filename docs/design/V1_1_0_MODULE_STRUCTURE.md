# 阅读页结构统一

> 发布说明：本文保留 1.1.0 规划时的背景；已采纳功能在 1.0.6 交付，当前状态见[发布记录](../RELEASE_1.0.6.md)。未采纳方案不代表当前实现。

2026-10-29 用户对照连接智能体、内在活动、共同线和记忆截图，指出结构不一致。本轮范围为这四页的共同外壳、筛选起点、概况和层级，保留品牌色与各页功能。

- 四个根容器标注 `module-content-shell`，共用明确单列、24px内容内边距与24px区域间隔，小窗口16px。
- 记忆/共同线/内在活动的独立只读标题行移除，只读标识移入第一个筛选栏；删除重复筛选解释，筛选栏不再另套大卡片。
- 记忆/共同线/连接页的概况共用紧凑结构，清除子块重复内边距/背景，左边线与正文一致。记忆概况显示数量而非大句子，共同线概况保留活动/归档数，连接概况为接入状态。外部页面标题保留。
- 内在活动的关注内容按16px普通正文显示，保留用户原文；reader上下重复内边距清除。用户数据、兴趣、统计、筛选、检索与接续行为不变。

在现有共享 module-shell 中集中规则。新增模块结构回归解析真实HTML和CSS，确认四页共用padding/单列契约、控制栏首先出现、无占位标题、只读标识和ID保留。现有常规检查、接入/设置/模型/数据检查通过。没有请求真实数据模型或操作用户界面。DOM/CSS契约不是几何或视觉验收，仍需用户在同尺寸窗口观察。
