# 智能体连接页与全局称谓

> 发布说明：本文保留 1.1.0 规划时的背景；已采纳功能在 1.0.6 交付，当前状态见[发布记录](../RELEASE_1.0.6.md)。未采纳方案不代表当前实现。

2026-10-29 用户要求产品文案不再使用「助手」，倾向「智能体」，并反馈连接页左侧活动区域过长。当前统一为「智能体」（英文 Agent），覆盖导航、设置、首页、日志、共同线与接入反馈；复制的接入说明同步使用 Agent。只改产品文案，不改用户已保存内容、API 名称或聊天协议角色。

## 连接页结构

1. 顶部用简短标题和本机服务/接入材料/文档状态说明当前准备情况。
2. 接入说明与复制/刷新操作前置，四步配置流程合入同一块；使用文档及版本改为次要的一行信息。
3. 活动放在操作区之后，分为智能体列表和 MCP 调用列表；各自使用最高 420px 的滚动区域，窄窗口上下排列。智能体依旧最多 8 个，调用最多 20 条，不改变后台数量或语义。长表格横向滚动局限于自身区域，表头在列表内固定。
4. 滚动区域设置命名 region 和 tabindex=0，保留键盘入口与焦点样式。复制凭据保护、刷新失败、最新请求与连接测试分开、客户端接收/使用尚未证明等状态继续保留。

原左侧活动区域同时叠放 8 个智能体与最多 20 次调用且没有自身高度边界，足以不断撑高页面。现已从布局约束修复，不把源码推断当成真实窗口复现。

语法、Settings 集成与接入接续专项通过，常规检查另记最终结果。没有用户窗口操作、真实模型调用、安装、提交推送或新包。本次称谓/连接页改动与上一轮成功提示 3 秒消失修复尚未包含在已交付的 model-settings-unsigned-20261029135500 包内。
