# 知识库阅读整理（2026-10-29）

> 发布说明：本文保留 1.1.0 规划时的背景；已采纳功能在 1.0.6 交付，当前状态见[发布记录](../RELEASE_1.0.6.md)。未采纳方案不代表当前实现。

本轮只整理标题层级和默认阅读，不调整全页搜索布局。

- 页面标题为「知识库」。阅读区单独显示文档标题（H2），路径和文件更新时间作为次要信息；正文标题从 H3 开始。与文档标题相同的首个一级标题只在渲染时省略，原文和章节锚点保留，参考阅读区遵循相同规则。
- 首次进入打开最近修改的文档。同一知识库恢复上次文档、章节引用和滚动位置；刷新保留当前阅读或当前活动条目。文档目录按文件修改时间降序排列，时间相同时按路径排序。通用接口默认仍按路径排序。
- 阅读偏好保存在本机界面的 localStorage，仅保存最近五个知识库的目录、文档引用与滚动位置。存储不可用时保留本次会话位置。上次文档确认不存在时提示并打开最近修改的一篇；权限错误和读取错误不冒充成功，不自动换文档。未连接、空库和列表读取失败保持独立提示。

默认阅读不写 Markdown，不触发模型请求或知识库索引生成。语义索引继续遵循已有本地模型限制。

自动检查使用临时合成知识库和内存 DOM，覆盖最近修改排序、跨知识库恢复、标题层级、缺失/权限/空库状态、刷新与手动选择竞态，以及原有双栏、锚点和回退行为。安装包通过源码比对和包内合成场景检查；实际窗口排版和滚动体验仍待用户验收。
