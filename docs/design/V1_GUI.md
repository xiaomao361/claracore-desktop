## 已实现的阅读顺序

顶部主导航是共同理解、记忆、知识、共同线、内在活动。痕迹、日志、连接助手和
设置保留在轻量工具区。导航允许换行，窗口顶部保留独立拖动空间。

首页使用现有共同线作为主题：

1. 选择正在阅读的主题。目录预览最多十条；当前选中项保留在预览中，完整目录
   从“全部共同线”进入。选择只改变本页阅读对象，不激活、重排或写回共同线。
2. 中心显示主题、当前位置与下一步。正文是有界预览，完整阅读进入同一条共同线。
3. 只有明确记录了 `confirmedGround` 才显示“共同线记录的理解”；只有
   `provisionalRead` / `misreadRisks` 有内容才显示“仍待厘清”。摘要不冒充确认结论。
4. 有引用时在侧面显示，最多六条；复制保留原文，全部引用可在共同线页阅读。
   未保存引用时把“尚未记录引用”收进正文末尾，让出阅读宽度，不据此判断没有依据。
5. 记忆、知识、共同线、内在活动以四个轻量入口汇聚到同一块阅读面。每个入口
   显示各自职责；已记录引用与当前共同线使用实线，其余保持虚线，不按最近时间
   猜测关联。未识别的路径和外部 URL 原样留在依据区，不强行归入模块。

四个模块采用无卡片的轻入口，不按同一 Agent 或最近时间猜测联系，
也不自动从 InnerLife 私有待分享内容取正文。实线仅表达本主题已记录的引用关系，
不表示引用内容已重新核对；虚线表达模块职责，不宣称已参与当前结论。
这里呈现的是共同线的记录，没有启动模型来生成新的综合结论。

2026-10-19 第二轮依据用户截图反馈，移除首页独立的白色地平线面板与 Canvas，
改为标题旁的小型存在标记，连接动态可原位展开。第三轮根据用户多 Agent 反馈，
每位 Agent 独立显示名称与状态，前景同时展示四位，更多观察可展开查看。近期活动
目录有界保留二十位；活跃请求优先，随后按最近观察排序。

标记按精确 Agent ID 保持稳定形状、色调与节奏，名称始终作为文字显示。Codex、
Lara、Clara、Claude 分别使用罗盘、叶形、花形与星形；其他 ID 使用稳定派生的
形状和首字。颜色之外仍可通过轮廓、名称与状态辨认，不要求靠颜色识别。
工具名与技术细节留在痕迹页。

光点只依据可观察状态：实时按 Agent 的运行请求计数支持“正在交互”；90 秒内的
请求显示“刚有活动”，较慢呼吸；15 分钟内显示“最近来过”，停止呼吸；过期后
显示“等待连接”。本地 HTTP 接入不提供持久在线会话，不能据完成请求声称在线。
运行请求快照超过 10 秒不继续证明正在交互；缺少可替代观察时回到待确认状态。

动效提供暂停按钮，尊重系统减少动态效果及应用动效设置，离开首页、窗口隐藏或
观察过期后停止。状态文字独立于动效。只设本地年龄过期计时器，不新增 API 轮询。
影响使用的错误继续独立显示，并提供日志入口。

第三轮的生命感同时来自静态与响应：形状各异、柔和底光、正在交互时更凝聚的
标记、不同相位的光晕，以及新活动才触发的一次涟漪。同一条记录刷新不重播；
离页、隐藏、暂停后清除涟漪。四模块入口的悬停响应保持轻微，相关连线仍保留
原有实线／虚线语义，不把装饰描绘成实时业务流转。

## 当前主题排版

首页有界预览与共同线完整阅读复用现有的安全 Markdown 渲染器，采用只读排版模式：
保留段落、显式小标题、列表、粗体和代码；独占一行的 `【最近进展】` 显示为小标题，
段内 `【本线说明】` 显示为强调。明确从①开始、按序且位于句子边界的清单才拆为
步骤，保留原编号、金额、日期、否定与尚未确认的表述。代码内或结构模糊的圈号
保持普通正文，不据内容猜测业务分组。

链接保留名称和目标文字，不在该阅读面生成跳转；原始 HTML 始终转义。标题稍作
收敛，正文限制舒适行宽，下一步按项排列。完整阅读保留所有正文与引用。
知识阅读器默认模式与链接行为保持原有契约。

记忆、共同线、内在活动的机制说明移到内容之后、默认折叠。原有阅读层、搜索、
配置和诊断入口保留。浅色与深色统一使用同一套语义 token。

## 读取与失败边界

- 复用 `getSharedLine({ lineId })`，同时核对返回包与当前位置的 line ID。
- 选中项变化后旧请求不能覆盖新内容；离开页面后旧的完整阅读请求不能抢回导航。
- 同一目录版本不重复读取。目录/当前对象更新后按需刷新；不新增轮询或模型调用。
- 加载、读取失败、无主题、未选择、没有当前位置及没有下一步分开表达。
- 当前选中主题消失后要求重新选择，不静默用另一条的内容替代。
- 主页面预览有限，完整共同线页保留完整摘要、下一步和原样引用。
- `factsUsed: []` 表示当前没有记录引用，不复活历史 metadata 中的旧引用。

## 实现入口与检查

- `app/views/home-understanding.js`：主题读取与首页正文。
- `app/views/home.js`：错误与连接组件集成。
- `app/views/home-connection.js`：请求观察、状态过期与动效生命周期。
- `app/views/shared-innerlife.js`：共同线完整阅读，包含全部引用。
- `app/knowledge-markdown.js`：知识页默认渲染与首页／共同线只读排版模式。
- `styles/views/shared-world-shell.css`、`styles/views/home-understanding.css`、`styles/views/home-world.css`：导航、阅读面与汇聚结构。
- `npm run test:home:understanding`：内存 DOM 检查，不启动用户 UI。
- `npm run check`：常规非交互回归，包含上述首页检查。
