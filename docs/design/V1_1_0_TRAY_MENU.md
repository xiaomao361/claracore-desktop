# 托盘菜单快捷入口（2026-10-29）

> 发布说明：本文保留 1.1.0 规划时的背景；已采纳功能在 1.0.6 交付，当前状态见[发布记录](../RELEASE_1.0.6.md)。未采纳方案不代表当前实现。

保留原生托盘菜单，按常用操作分组：

- 顶部显示应用版本与进程运行状态；此状态不代表模型或 MCP 服务健康。
- 显示、隐藏主窗口。
- 「前往」子菜单直达共同理解、记忆、知识库、共同线、内在活动与日志。
- 直接进入连接智能体、设置。
- 打开知识库文件夹、数据文件夹；尚未设置知识库时进入知识库页面。权限、配置损坏和打开失败继续报错，不冒充成功或跳到其他目录。
- 退出应用。

菜单使用中英文文案，跟随现有界面语言。页面跳转通过受限 IPC 事件和现有 setView 路由，预加载订阅完成后通知主进程就绪。启动或重载期间只保留最后一次目的地，避免丢失操作或重复导航。订阅不向页面暴露 Electron 事件对象；主进程只接受主窗口的就绪通知。

自动检查覆盖菜单操作、页面路由、双语、启动/重载竞态、错误上报及预加载订阅顺序。未执行宿主窗口、托盘或文件夹操作，原生菜单体验待用户验收。

本地测试包：`dist-lite/test-1.0.6-tray-shortcuts-unsigned-20261029153820/ClaraCore-Desktop-1.0.6-lite-arm64.dmg`（macOS Apple Silicon，未签名未公证）。SHA-256：`728d3a5b1c203fbc04d62ac1918686bb75fa65498bce25a5b0c27f48f4a6b54f`。

`npm run check`、`git diff --check`、包内托盘行为合成测试、235 个产品源码文件比对、隔离 Gateway、新安装默认值、Lite 结构和 DMG 只读完整性检查通过。未启动应用 GUI。
