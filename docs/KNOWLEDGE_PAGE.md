# Knowledge reader

## 阅读顺序

独立「知识」入口沿用现有导航与浅/深色主题。默认显示简洁工具栏与文档目录、单栏正文；搜索和“管理”互斥展开。目录异常单独显示；可用时不展示大块状态信息。“管理”保留目录设置、手动刷新、按需展开的最近收录与材料保存；目录索引只有缺失、过期或损坏时才显示重建操作。语义索引维护只在检索方式选为语义或混合时出现，检索无下一页时不展示翻页按钮。

- 目录：所选知识目录下的 `notes/`、`topics/`、`inbox/` 分别对应笔记、主题、待整理；默认「笔记与主题」只合并前两者，不包含根目录和 `inbox/` 中的 Markdown。各范围递归列出 `.md`，每页 10 篇，按当前页路径分组折叠；目录栏整体可收起。目录列表独立滚动，翻页保持在底部，切换范围或翻页后从列表顶部开始。空状态属于所选范围。
- 阅读：使用当前 Markdown，展示标题、段落、列表、表格、引用和代码块；原始 HTML 始终转义。没有自动加载远程图片或抓取外部内容。
- 关联：文章小节、库内内联链接、反向链接、返回刚才阅读、复制文档或段落指针。复制按钮随当前指针是否包含小节锚点更新文案；跳转后聚焦目标小节。找不到锚点时保留文档并说明缺失，读取文档失败时清除上次正文。
- 状态：目录未选择、缺盘、权限/配置问题、无文档、失效链接、索引缺失/过期/损坏分别显示。服务错误不转换成“没有资料”。
- 更新：进入页面或点击刷新读取新状态，无后台监听或轮询。重建索引由用户显式点击，结构索引不代表语义向量已建立。

Markdown 阅读器支持内联链接，已有引用式链接等未支持的语法保持文字显示；不声称完整 CommonMark 支持。库内链接在所选目录内读取。HTTP/HTTPS 来源链接只有用户点击后才通过专用 IPC 交给系统打开；脚本、文件协议和 URL 内凭据拒绝。当前支持单栏与双栏对照阅读：正文或关联区的库内链接打开右侧参考栏，原文保持不变；参考栏继续跳转只更新参考栏。两栏的篇内目录只定位本栏。参考栏提供独立返回、关闭和“在主栏阅读”；主栏返回恢复之前的滚动位置。两个栏位使用独立请求序号，关闭、换根目录或停用页面会使过期参考响应失效。两栏 DOM 锚点 ID 分开，避免同一文档对照时冲突。

宽窗口采用左右分栏，分隔线可拖动，键盘方向键每次调整 2%，Home/End 到 30%/70% 边界。窄于 960px 时参考区上下排列、分别滚动；低于 600px 时目录放在上方。所有正文仍通过既有 readKnowledgeDocument 接口读取，没有增加本地文件直读或远端调用。

## 最近收录与材料入口

最近收录默认 10 条，可加载下一页，列表只带路径、类型、状态与时间。点开 Agent 草稿读取准确增量及到期时间；草稿提交权仍属于创建该预览的调用者。点开已保存回执，可直接阅读目标段落；步骤和恢复资料放入按需展开的详情。部分记录损坏时显示可读记录及错误数量，不将异常记录当作零记录。

草稿只存在于当前进程并受原有 30 分钟有效期约束；应用重启或过期后不再显示。回执来自当前目录对应的 userData 状态目录。结构索引与最近收录互相独立；待整理不会因出现在目录页面就进入正文检索索引。

“保存材料到待整理”接收标题、来源、日期、保留理由和可选原文。只保留来源链接时原文可留空。软件为 inbox 文档生成文件名，使用相同 preview/commit 服务，先展示准确增量再保存。原文以代码块字面保留，保留已有 Markdown/链接文本，不把材料自动升格为用户立场或整理完成的文章。用户输入保留在当前窗口表单中，未承诺跨重启保存。

保存响应不确定时保留 token 并冻结拟稿输入，再次保存会重试同一次收录。结束预览可解锁输入；提示先检查最近收录和实际文档，避免创建重复材料。切换目录使旧预览失效，保留表单输入。服务返回部分完成时提供实际文档入口和明确提示。


## 检索

支持文字、语义和混合模式，默认文字检索。语义索引需要显式建立；正文或模型改变后重新建立。混合模式的语义部分失败会保留文字结果并返回 partial。见 [检索契约](KNOWLEDGE_SEARCH.md)。


## 局部读取失败

目录中单篇超限或不可读的文档保留带原因的条目，其他文档仍可打开。
默认阅读优先选择当前页可读文档。反向链接扫描遇到不可读文档会标为部分结果，
显示失败文档数；不能把不完整扫描当作没有链接。正文/章节的错误码通过 IPC 保留，
使缺失、权限和一般读取失败仍可区分。
