# 0.9.2 — 首页长标题布局修复

2026-10-15，本地 Lite 测试修复版本，接续 0.9.1；未公开发布。

用户截图显示：共同线标题包含项目路径并换行后，摘要与按钮挤入动态线区域。
原因是首页文字层绝对定位，动态线固定在整个卡片的约中部，文字增长不改变它的位置。

本次将标题/摘要/按钮、动态线、最近活动放在正常文档流的独立网格行中，让卡片随
内容增高；长路径和连续英文允许换行。重复的动态线标题限制为一行省略，Agent 标记
与 Canvas 均按场景实际宽度采用同一断点。错误提示留在首段文字内，不再悬在其他区域上。
原有主题、字体尺度、动作与动画预算保留，不改变共同线数据或授权配置。

已有窗口回归补充 1440/1100/900/720 宽度的路径标题与连续英文覆盖，核对区域不重叠、
按钮位置与横向溢出；本轮没有窗口操作授权，因此该窗口用例未运行，实际视觉验收待用户。
